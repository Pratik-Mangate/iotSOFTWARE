About This Project

DermaScan Skin Monitor is a dermatological decision-support prototype engineered to evaluate how fine-tuned deep convolutional networks can assist clinical image triage. The application takes clinical photographs, applies ImageNet-standardized normalization transforms, and performs forward inference via a fine-tuned EfficientNet-B0 backbone.

Inference & Execution Pipeline

To guarantee real-time evaluation speeds across all consumer operating systems without native C++ DLL conflicts, inference is executed using ONNX Runtime with the CPUExecutionProvider. The model weights are contained within a single optimized graph representation, eliminating external dependencies at runtime.

Local Data Security & Patient Privacy

All submitted images, preprocessed tensors, and historical prediction records remain strictly stored on the local server. No telemetry or biometric data is transmitted to cloud APIs or third-party analytical endpoints. Case records can be purged at any time from the evaluation registry.

Clinical Device & Wi-Fi Access Protocol

To access this interface from an Android smartphone or tablet on the same Wi-Fi network:

  1. Verify both the host machine and mobile phone are joined to the same Wi-Fi network.
  2. Note the Phone URL displayed in the server terminal (e.g. http://192.168.1.x:5000).
  3. Open Google Chrome on Android and navigate directly to the address.
  4. Tap Take Photo (Rear Camera) to capture lesions with the phone camera directly into the model.
